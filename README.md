# pagelet

A page builder for Rails + React: a visual drag-and-drop editor, a renderer that
draws saved pages with your own React components, and a Rails engine that stores,
versions and publishes them.

**Under development.** This early release reserves the name and contains no
functionality yet.

Not related to the older `pagelet` npm package from the BigPipe project.
